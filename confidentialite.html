Règles de confidentialité

Jarvis est une application personnelle utilisée uniquement par son propriétaire, avec son propre compte Google.

  • Données consultées : les événements de l'agenda Google (lecture, création, modification) et les e-mails Gmail (lecture seule).
  • Usage : uniquement pour répondre aux demandes du propriétaire. Aucune donnée n'est vendue, partagée avec des tiers ni utilisée à des fins publicitaires.
  • Stockage : les jetons d'accès restent sur le serveur privé du propriétaire, inaccessibles depuis internet.
  • Révocation : l'accès peut être retiré à tout moment sur myaccount.google.com/permissions.

L'utilisation des données reçues des API Google respecte les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.
